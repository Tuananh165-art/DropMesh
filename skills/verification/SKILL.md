# DropMesh verification

Map each spec criterion to a test or external check. Run focused unit/integration tests, malformed-input fuzz smoke, E2E, vet, race, static analysis, vulnerability scan, platform builds, and relevant benchmarks. Record commands, exit codes, toolchain, and limits. Loopback tests do not prove LAN behavior; cross-compilation does not prove runtime behavior. Keep the physical two-device/no-Internet test blocked until actually run.
